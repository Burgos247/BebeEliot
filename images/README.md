# 📁 Imágenes

Sube aquí la imagen del osito (el cartel de "Mi Baby Shower") para usarla en el hero.

## Cómo subirla (en GitHub)
1. Asegúrate de estar en la rama **`diegoandres`**.
2. **Add file → Upload files** y arrastra la imagen dentro de esta carpeta `images/`.
3. Ponle un nombre sencillo, por ejemplo: **`pooh.png`** (o `pooh.jpg`).
4. **Commit** a `diegoandres`.
5. Avísame el **nombre exacto del archivo** y lo incrusto en el hero.

## Recomendación de formato
- **PNG** → si el osito está recortado (fondo transparente). Se integra perfecto.
- **JPEG** → si la imagen trae su propio fondo. También funciona.

> La configuración de Vercel ya está lista para servir lo que subas en esta carpeta.
